# 900 Devirde Barış Antlaşması

## Resmi Durum Bildirimi

Bu depo, çamaşır makinesinin tamburunda 900 devir/dakika hızında toplanan olağanüstü zirvenin tutanaklarını içerir. Katılımcılar: bir çorap (sol), bir çorap (sağ, kayıp), bir havlu ve Uluslararası Durulama Komisyonu.

Proje **bilimsel**, **ciddi** ve **hiçbir şekilde şaka değildir**. Eğer gülüyorsanız antlaşmayı yanlış okuyorsunuzdur.

## Neden 900 Devir?

- 400 devir: yumuşak diplomasi
- 800 devir: gerilim
- **900 devir:** tarih yazılır, lekeler çözülür, taraflar sıkılır

## Kurulum

```bash
python3 antlasma.py
```

Python 3 yeter. Başka paket yok. Barış sade olmalıdır.

## Kullanım

Program, yıkama-durulama-sıkma döngüsünü hukuki madde madde yürütür. Her turda bir madde okunur. Program bitince antlaşma yürürlüğe girmiş sayılır. Makineniz yoksa hayal gücünüz yeter.

## Madde Özeti (kesinlikle resmi)

1. Hiçbir çorap tek başına sürgüne gönderilemez.
2. Durulama hakkı vazgeçilemez bir haktır.
3. Aşırı sıkma işkencedir; 900 devir istisnadır çünkü barış içindir.
4. Kumaş yumuşatıcı tarafsız bölge ilan edilir.
5. Kayıp çoraplar için araştırma komisyonu kurulur, sonuç beklemeden dağıtılır.
